Every resource is free, official, and on Microsoft Learn. Follow the phases in order. The path ends where the top 1% live: DirectX and the Win32 Application Programming Interface (API), called directly, without a framework in the way.

Phase 1

Platform Foundation

Understand the two SDKs before writing a line of code.

  • Windows Developer Platform Overview
    learn.microsoft.com/en-us/windows/apps/get-started/
    The authoritative overview. Explains the relationship between the Windows SDK (OS-level APIs) and the Windows App SDK (modern, decoupled APIs including WinUI 3). Read this first.
  • Set Up Your Environment
    learn.microsoft.com/en-us/windows/apps/get-started/start-here
    Installs Visual Studio 2026 with the required WinUI and Windows App SDK workloads via a single WinGet configuration file. Run this before anything else.
Phase 2

WinUI 3

Microsoft's current native UI framework. Fluent Design, XAML, C#.

  • WinUI 3 Overview
    learn.microsoft.com/en-us/windows/apps/winui/winui3/
    The canonical reference. Covers the programming model, Fluent Design integration, and the relationship to the Windows App SDK. Bookmark it.
  • WinUI Notes Tutorial
    learn.microsoft.com/en-us/windows/apps/tutorials/winui-notes/intro
    Builds a real note-taking app. Covers XAML markup, C# code-behind, file I/O, data binding, and page navigation. The best hands-on starting point.
  • WinUI 3 Gallery
    learn.microsoft.com/en-us/windows/apps/dev-tools/samples
    Install this app from the Microsoft Store. Every control, every style, every design pattern, with live XAML source. Keep it open while building.
  • Windows App SDK Samples
    learn.microsoft.com/en-us/windows/apps/dev-tools/samples
    Production-grade code covering app lifecycle, windowing, push notifications, and WinUI 3 integration. Study these after the tutorial.
Phase 3

Win32 API

The foundation everything runs on. Read it to understand it.

  • Win32 API Reference
    learn.microsoft.com/en-us/windows/win32/
    Do not read this cover to cover. Focus on three areas: window management, the message loop, and input handling. Every framework above this calls into these APIs. Knowing them separates intermediate from advanced developers.
Phase 4

DirectX

Top 1% territory. Browsers and game engines live here.

  • Getting Started with DirectX Graphics
    learn.microsoft.com/en-us/windows/win32/getting-started-with-directx-graphics
    For 2D graphics and text: Direct2D and DirectWrite. For 3D: Direct3D 11. For compositing: DirectComposition. Understand which API does what before writing code.
  • Roadmap for Desktop DirectX Apps
    learn.microsoft.com/en-us/windows/win32/direct3dgetstarted/roadmap-for-metro-style-apps-using-directx
    Microsoft's own sequenced learning path for DirectX and C++. Covers environment setup, the Win32 integration layer, and sample applications. Use C++/WinRT for new projects.
